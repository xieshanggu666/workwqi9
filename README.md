# 回测工坊：个人投资回测与风险分析平台

一个可本地运行的个人投资策略回测与风险分析平台。内置模拟行情引擎、技术指标库、回测撮合器、风险指标与蒙特卡洛模拟，提供 Web 交互界面。

## 快速开始

```bash
npm install
npm run dev
```

启动后自动打开浏览器（自动选择空闲端口）。`npm test` 运行测试套件。

## 架构

```
invest_backtest/
├── engine/
│   ├── market.js       模拟行情生成（GBM + 波动率状态切换 + 前复权）
│   ├── indicators.js   技术指标（SMA/EMA/RSI/MACD/布林带/ATR）
│   ├── backtest.js     回测撮合器（信号延迟一日、止损止盈、成本模型）
│   ├── metrics.js      风险指标（年化/夏普/索提诺/最大回撤/卡玛）
│   ├── montecarlo.js   自助法蒙特卡洛模拟
│   ├── snapshot.js     参数快照（白名单归一化 / 稳定哈希 / 深冻结 / MC 种子策略）
│   ├── runner.js       快照运行器（回测+风险指标+蒙特卡洛共用同一快照）
│   └── store.js        策略库状态机（草稿/评审/发布/驳回/撤回 + 角色权限 + 运行留痕）
├── server.js           HTTP 服务（静态托管 + 回测 API + 策略工作流 API）
├── web/                Vue3 + Canvas 前端（策略库 / 沙箱试算两个视图）
└── tests/              引擎与工作流测试套件
```

## 策略版本与审批工作流

三种角色（前端右上角切换，经 `X-Role` 头传入）：**策略作者 / 评审员 / 投资者**。

```
draft 草稿 ──作者送审──▶ in_review 评审中 ──评审员通过──▶ published 已发布（成为当前发布版本）
   ▲                          │
   └──── 作者修改 rejected ◀──┴──评审员驳回（退回作者）
                              published ──作者撤回──▶ withdrawn 已撤回
```

- **存草稿送审**：作者可反复保存草稿；点「送审」时快照被**深冻结**并计算 sha256 哈希，此后版本参数只读。
- **通过发布 / 驳回退回**：评审员在评审中版本上「通过」（成为当前发布版本）或「驳回」（带意见退回，作者改后重新送审）。
- **投资者只运行已发布版本**：服务端强制——只有「当前发布版本」允许投资者运行；草稿/评审中/已驳回/已撤回/非当前旧版一律 403。
- **同一参数快照**：回测、风险指标、蒙特卡洛由 `runner.runSnapshot(snapshot)` 一次产出，三处不可能出现不同参数；MC 种子策略（随市场种子 `seed+1` 或固定种子）也记录在快照与每次运行上。
- **撤回不改历史结果**：撤回只把版本状态置为 `withdrawn` 并清空当前发布指针；历史运行记录只追加、永不重写或删除，记录里留存快照哈希，用同版本再跑结果逐位一致。
- **旧版仍可直接回测**：发布新版本不改动旧版本状态，旧版仍为 `published`；作者/评审员可对任意已冻结版本（含评审中、已撤回、旧发布版）直接回测，投资者仅限当前发布版。
- **每个策略至多一个开放版本**（草稿/评审中/已驳回），关闭后才能基于当前发布参数新建下一版草稿（`base_version` 记录血缘）。
- 草稿/驳回版本可「试算」：仅作者、不产生运行记录；正式「运行」要求版本已冻结并追加一条历史记录。

数据持久化在 `data/strategies.json`（可用 `STRATEGY_DB` 环境变量覆盖路径），原子写入。

## API

### 沙箱（即席，不入库）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/system` | 系统信息（含角色列表） |
| POST | `/api/market` | 生成模拟行情 |
| POST | `/api/backtest` | 行情 + 策略 + 交易参数，返回权益曲线/回撤/逐笔交易/风险指标 |
| POST | `/api/montecarlo` | 对权益曲线做蒙特卡洛模拟 |
| POST | `/api/snapshot/run` | 传入完整快照，一次返回回测+风险指标+蒙特卡洛（共用快照） |

### 策略库工作流（`X-Role: author|reviewer|investor`）

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| GET/POST | `/api/strategies` | 全部 / 作者 | 列表 / 创建策略（含 v1 草稿） |
| GET/PATCH | `/api/strategies/:id` | 全部 / 作者 | 详情（版本+运行记录）/ 改名称描述 |
| POST | `/api/strategies/:id/drafts` | 作者 | 基于当前发布版新建下一版草稿 |
| PUT | `/api/strategies/:id/versions/:v/draft` | 作者 | 保存草稿（仅 draft/rejected 可改） |
| POST | `/api/strategies/:id/versions/:v/submit` | 作者 | 送审（此刻冻结快照） |
| POST | `/api/strategies/:id/versions/:v/review` | 评审员 | `{decision: approve\|reject, comment}` |
| POST | `/api/strategies/:id/withdraw` | 作者 | 撤回当前发布版本 |
| POST | `/api/strategies/:id/versions/:v/run` | 投资者限当前发布版；作者/评审员限已冻结版 | 运行并追加历史记录 |
| POST | `/api/strategies/:id/versions/:v/trial` | 作者 | 草稿/驳回版试算，不留痕 |

## 核心语义

- **信号延迟**：策略在第 `i` 根 K 线收盘后产生信号，于第 `i+1` 根开盘成交，杜绝前视偏差。
- **止损止盈**：持仓期间按当日最高/最低价触发；若开盘跳空越过触发价，按开盘价成交；止损/止盈平仓当日不再进场。
  - `stopMode: "fixed"`（默认）：固定比例，`stopLoss`/`takeProfit` 为相对入场价的百分比；不传 `stopMode` 的旧参数与历史结果逐位一致。
  - `stopMode: "atr"`：入场当日锁定触发价，距离 = `ATR(atrN)` × 倍数（`atrStopMult`/`atrTargetMult`）× 波动状态乘数。ATR 与波动状态只引用**入场前一根**（`i-1`）数据，无前视；预热期 ATR 不足时回退固定比例（比例为 0 则不设止损止盈）。
  - `stopMode: "trail"`：可追踪规则。入场当日与 `atr` 同价起步，此后**每个交易日**用截至前一根 K 线的 ATR 与波动状态重算退出价：止损锚定持仓期最高收盘价（吊灯式），**只紧不松**；止盈锚定入场价，距离随最新 ATR × 波动乘数每日收放。波动变化因此逐日反映到退出价格上；预热期同样回退固定比例，ATR 可用后自动接入追踪。
  - 波动状态：`ATR / ATR 的 atrVolN 均值 ≤ volLowK(0.7)` 为低波动（乘数 `volLowMult=0.8`，收紧），`≥ volHighK(1.3)` 为高波动（乘数 `volHighMult=1.5`，放宽），否则正常（乘数 1）。
  - 逐笔交易统一记录 `stop_price`/`target_price`（平仓当日实际生效价）、`stop_init`/`target_init`（入场当日初始价）、`stop_updates`（追踪收紧次数）与 `stop_mode`/`atr_ref`/`vol_state`/`vol_mult`；固定与 ATR 模式初始价等于锁定价、调整次数为 0，`atr_ref` 为 `null` 表示固定比例兜底。回测撮合、风险指标与前端展示共用同一套历史解释。
- **成本模型**：成交价叠加滑点（买入上浮、卖出下浮），双边收取手续费。
- **风险指标**：收益序列采用对数收益，年化按 252 个交易日折算；下行波动只统计负收益；最大回撤记录回撤区间。
- **蒙特卡洛**：对历史对数收益自助重采样生成模拟路径，输出 5%/50%/95% 分位带与亏损概率。
